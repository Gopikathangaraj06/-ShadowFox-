# Advanced Data Analysis using Jupyter Notebook

## Objective
To perform a complete data analysis workflow using a Jupyter Notebook by
selecting a dataset, exploring its structure, defining a research question,
and deriving insights through data visualization.

## Dataset Description
The dataset used in this project consists of student marks across three
subjects: Mathematics, Science, and English. It includes multiple students
and their respective scores, allowing for comparative academic analysis.

## Research Question
Which subject has the highest average score among students?

## Methodology
The analysis was conducted using the following steps:
1. Creation and loading of the dataset into a Pandas DataFrame.
2. Exploratory Data Analysis (EDA) to understand the structure and data types.
3. Calculation of average scores for each subject.
4. Visualization of subject-wise averages using bar charts.
5. Interpretation of results based on visual and numerical insights.

## Tools and Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib

## Key Findings
The analysis revealed that **Science** has the highest average score among
the three subjects. This indicates stronger overall student performance in
Science compared to Mathematics and English.

## Conclusion
This project demonstrates the ability to perform end-to-end data analysis
using Python. It highlights skills in data exploration, analytical thinking,
visualization, and clear presentation of insights within a Jupyter Notebook
environment.
